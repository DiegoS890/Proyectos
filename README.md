#Portafolio de proyectos

Este repositorio reúne algunos de mis proyectos y prácticas de desarrollo web, realizados como parte de mi proceso de aprendizaje y formación en programación.

Los proyectos abarcan diferentes conceptos fundamentales del desarrollo web, desde la creación de interfaces y lógica con JavaScript hasta la gestión de datos y el desarrollo de aplicaciones web con PHP y SQL.

Proyectos

Landing Page: Página web desarrollada con HTML y CSS, enfocada en la estructura, diseño y organización de una interfaz web. Este proyecto fue realizado siguiendo los ejercicios y objetivos propuestos por The Odin Project.

Calculadora: Aplicación interactiva desarrollada con HTML, CSS y JavaScript, que permite realizar operaciones matemáticas básicas. El proyecto usa conceptos de lógica, manipulación del DOM y eventos en JavaScript.

Registro de usuarios: Aplicación web de práctica desarrollada con HTML, CSS, PHP y SQL. Permite trabajar con formularios y almacenamiento de información de usuarios en una base de datos. Para el desarrollo y las pruebas se utilizó XAMPP, utilizando su servidor local para ejecutar PHP y conectarse a la base de datos mediante MySQL.

Estos proyectos representan parte de mi aprendizaje práctico en desarrollo web y muestran mi experiencia trabajando con tecnologías de frontend, backend y bases de datos.
